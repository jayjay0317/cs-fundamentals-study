# CS Glossary

A collection of important computer science terminology encountered throughout my studies.

## A

### Algorithm
A finite procedure or sequence of steps used to solve a computational problem.

### Amortized Analysis
A method of analyzing the average cost per operation over a sequence of operations, allowing occasional expensive operations.

### Array
A data structure that stores elements in a contiguous block of memory and supports constant-time indexed access.

### Asymptotic Analysis
The study of how an algorithm's resource usage, such as running time or memory, grows as the input size becomes large.

## B

### Base Case
The simplest case of a recursive problem that can be solved directly without making another recursive call.

### Big-O Notation — $O(\cdot)$
Describes an asymptotic upper bound on the growth of a function.

### Binary Search Tree (BST)
A binary tree where keys in the left subtree are smaller and keys in the right subtree are larger.

### Binary Tree
A tree in which each node has at most two children.

## C

### Capacity
The number of memory slots currently allocated for a dynamic array, which may be larger than the number of stored items.

### Collision
When two distinct keys are mapped to the same hash-table index.

### Comparison Model
A model in which an algorithm determines the relative order of items only by comparing their keys.

### Computational Problem
A problem defined in terms of possible inputs and the required outputs for those inputs.

### Constant Factor
A fixed multiplier that does not depend on the input size $n$. Constant factors are generally ignored in asymptotic analysis.

### Contiguous Memory
A region of memory in which data is stored in consecutive memory locations.

### Correctness
The property that an algorithm produces the required output for every valid input.

## D

### Data Structure
A way of organizing and storing data together with the operations that can be performed on it.

### Depth
The number of edges from a node to the root.

### Destructive
Describes an operation or algorithm that modifies its original input.

### Dynamic Array
An array that can grow or shrink by allocating new memory when necessary. It typically keeps extra capacity to avoid resizing after every insertion.

## E

### Efficiency
A measure of the computational resources required by an algorithm, often expressed in terms of running time or space as a function of input size.

## F

### Fundamental Operation
A basic operation assumed to require a fixed amount of time under a chosen model of computation.

## H

### Hash Function
A function that maps a key to an index in a hash table.

### Hash Table
A data structure that uses hashing to support fast key-based operations.

### Height
The number of edges in the longest downward path from a node to a leaf.

## I

### In-Place
Describes an algorithm that uses only a constant amount of additional memory beyond the input.

### Interface
A specification of the operations a data type supports, independent of how those operations are implemented.

## L

### Linked List
A pointer-based data structure in which each node stores an item and a reference to the next node.

### Load Factor
The ratio of stored items to hash-table slots, $\alpha = n/m$.

## M

### Machine Word
A fixed-size group of bits that a processor can operate on as a unit. A $w$-bit word contains $w$ bits.

### Memory Allocation
The process of reserving a block of memory for storing data.

### Model of Computation
A simplified model that defines the basic operations available to an algorithm and the cost assigned to those operations.

## O

### Omega Notation — $\Omega(\cdot)$
Describes an asymptotic lower bound on the growth of a function.

## P

### Pointer
A value that refers to the memory location of another object or data item.

## R

### Random Access
The ability to access an element directly by its position without traversing the preceding elements.

### Recurrence Relation
An equation that describes the running time of a recursive algorithm in terms of smaller input sizes.

### Recursion
A technique in which a function solves a problem by calling itself on smaller versions of the same problem.

## S

### Sequence
An interface in which items are organized and accessed according to their position or order.

### Set
An interface in which items are identified by unique keys rather than by position.

### Stable Sorting
Sorting that preserves the relative order of items with equal keys.

### Static Array
An array with a fixed amount of allocated space that cannot directly grow or shrink.

## T

### Theta Notation — $\Theta(\cdot)$
Describes an asymptotically tight bound, giving both an upper and lower bound of the same order.

### Traversal
The process of visiting nodes of a tree in a defined order.

## U

### Universal Hashing
A randomized hashing method designed to keep collision probability small.

## W

### Word-RAM Model
A model of computation in which data is stored in fixed-size machine words and common operations on those words are treated as constant-time operations.
