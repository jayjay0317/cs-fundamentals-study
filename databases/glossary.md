# Database Glossary

## C

### Cardinality

The number of instances of one entity that can be associated with an instance of another entity in a relationship.

### Crow's Foot Notation

A graphical notation used in entity relationship diagrams to represent the minimum and maximum cardinality of relationships.

## D

### Database

An organized collection of data that supports efficient storage, retrieval, and modification.

### Database Management System (DBMS)

Software used to create, manage, and interact with databases.

## E

### Entity Relationship Diagram (ERD)

A visual representation of entities, their attributes, and the relationships between them in a database.

## F

### Foreign Key

A column or combination of columns that references a primary key or another eligible unique key in the same or another table, establishing a relationship between records.

## J

### Junction Table

A table used to implement a many-to-many relationship by storing foreign keys that reference the related tables.

## P

### Primary Key

A column or combination of columns that uniquely identifies each record in a table and cannot contain NULL values under the relational model.

## S

### Schema

The defined structure of a database, including its tables, columns, data types, constraints, and relationships.

### SQLite

A lightweight, embedded relational database engine that does not require a separate database server.
