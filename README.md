# CS Fundamentals Study

A structured study repository for strengthening core computer science fundamentals, with a focus on data structures and algorithms, database systems, and operating systems.

The goal is to build a practical understanding of how core CS concepts work, why they are useful, and what trade-offs they involve, with particular relevance to data science and machine learning.

## Learning Goals

- Strengthen core computer science fundamentals.
- Develop stronger algorithmic reasoning and problem-solving skills.
- Understand important database concepts beyond SQL syntax.
- Build a practical understanding of operating systems.
- Maintain concise notes, implementations, and practice solutions for future review.

## Learning Roadmap

### Data Structures & Algorithms

Asymptotic analysis, arrays and dynamic arrays, sorting, hashing, trees, binary search trees, heaps, priority queues, graphs, BFS, DFS, shortest paths, recursion, dynamic programming, and computational complexity.

### Database Fundamentals

Relational model, schema design, keys, normalization, constraints, indexes, query processing, transactions, ACID properties, and database performance.

### Operating Systems

Processes, threads, CPU scheduling, stack and heap, virtual memory, concurrency, synchronization, file systems, storage, and CPU-memory-disk interactions.

## Study Approach

For each topic, I aim to:

1. Build an intuitive understanding.
2. Learn the formal terminology and technical details.
3. Explore a small example or implementation.
4. Analyze time and space complexity where applicable.
5. Solve a small number of targeted practice problems.
6. Summarize key ideas, trade-offs, and personal insights.

The emphasis is on understanding **why and when** a concept is useful rather than simply memorizing definitions or implementations.
